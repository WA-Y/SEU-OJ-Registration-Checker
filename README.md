# SEU-OJ 报名核验

> 东南大学 OJ 新生赛报名信息的半自动化校对工具

用于新生赛报名表的半自动化校对：识别报名表 → 获取 OIerDb 获奖数据 → 筛选「可能获奖」的新手组选手 → 人工确认 → 按校区分组导出结果。

本项目面向东南大学 OJ 赛事组织者，帮助快速完成报名资格核验，避免人工逐条比对获奖名单。


在线网页：https://seu-oj-checker.app.workbuddy.host/?sharecode=MU34GM3VDK

## ✨ 特性

- **鲁棒识别报名表**：自动扫描 Excel 各 sheet，模糊匹配「姓名 / 学号 / 一卡通 / QQ / 年级 / 组别 / 校区」等表头，支持组别多选、校区分列
- **自动匹配获奖数据库**：对接 [OIerDb](https://github.com/OIerDb-ng/OIerDb) 获奖名单，按姓名 + 入学年份推算判断是否「可能获奖」
- **同名智能区分**：按 UID 独立区分同名选手，标注「可能本人 / 同名非本人」，附完整获奖轨迹与年级
- **可视化工序**：待确认 / 已通过 / 草稿箱三栏，卡片式交互，支持搜索、撤销、回退
- **一键导出**：按「校区 × 组别」4 组输出 Excel + JSON

## 🚀 快速开始

### 环境要求

- Python 3.8+
- Windows / macOS / Linux

### 安装与运行

```bash
# 1. 克隆仓库
git clone <你的仓库地址>
cd seu-oj-registration-checker

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python run.py
```

启动后浏览器会自动打开 `http://127.0.0.1:8765`。

> 首次使用需联网获取 OIerDb 获奖数据（约 13MB）；下载后缓存到 `data/` 目录，之后可离线使用。

## 📖 使用流程

1. **设置年份**（默认 2026）
2. **加载报名表**：填入报名 Excel 路径（可直接拖文件进输入框），点「加载报名表」
3. **获取 OIerDb 数据**：点「获取 OIerDb 数据」，自动下载并解析获奖名单
4. **执行筛选**：点「执行筛选」，找出「报了新手组（大一/大二）但历史获过奖且年级对得上」的选手，进入「待确认」栏
5. **人工确认**：核对每个疑似获奖选手（可查看其完整获奖详情），确认报名成功或取消资格
6. **导出结果**：点「导出结果」，在 `output/` 目录生成 4 组 Excel + JSON

## 🔍 筛选逻辑

- OIerDb 中获奖人的「初中入学年份」+ 6 年 = 推算的大学入学年份（初中 3 年 + 高中 3 年）
- 报名人的大学入学年份由报名表年级解析（如「大一（26 级）」→ 2026）
- 若某人报了新手组（大一/大二）、名字在 OIerDb 获奖名单中、且推算的大学入学年份与报名年份之差 ≤ 1，则判定为「可能获奖」，需人工确认
- 专业组选手直接视为报名成功，不参与新手筛选
- **同名处理**：OIerDb 中存在多个同名者时，按 UID 独立区分，分别列出各人的入学年份轨迹，标注「可能本人 / 同名非本人」

## 📤 导出分组（4 组）

| 分组 | 说明 |
|---|---|
| 四牌楼校区_大一大二组 | 四牌楼校区的大一组 + 大二组 |
| 四牌楼校区_专业组 | 四牌楼校区的专业组 |
| 九龙湖校区_大一大二组 | 九龙湖校区的大一组 + 大二组 |
| 九龙湖校区_专业组 | 九龙湖校区的专业组 |

每组同时输出 `.xlsx`（Excel）和 `.json` 两个文件，包含姓名、学号、花名、一卡通号、手机号、QQ、年级、组别、校区。

> 若某位同学同时报名多个组别，会同时出现在对应的多个分组文件中。

## ❓ 常见问题

- **获取 OIerDb 数据失败 / 网络错误**：OIerDb 数据源需要能访问外网，可重试。或手动将 `oierdb.json`（格式 `[{"name":"姓名","grade":初中入学年份,"records":[...]}, ...]`）放到 `data/` 目录后重新点「获取 OIerDb 数据」。
- **识别不到某列**：报名表表头需包含「姓名 / 学号 / 一卡通 / QQ / 年级 / 组别 / 校区」等关键词，程序已做模糊匹配。
- **组别分散在多列**：程序会自动合并所有含「组别」的列，并拆分多选值（如「大一组, 专业组」）。
